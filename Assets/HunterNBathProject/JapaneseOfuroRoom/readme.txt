============================
Japanese Ryoukan-Style Bath
By Hunter Nance
============================

Thank you for supporting my first asset pack. While I was visiting Matsuyama the other month I stayed in a ryoukan that I thought had a very
creepy vibe, so I took a lot of reference pictures and decided to challenge myself to learn 3d modeling by modeling some of the environments.
I think it would lend itself well to a horror game in many ways, so I started with this ofuro room. I hope it will be useful to you.

Asset List:
-Bath Scene
-Door with window
-Wall and windows with blinds
-Bath/ofuro with water shader and Jetstream particles
-Japanese style wooden bath seat
-Bath stirrer ("yukakibou")
-Floor/wall tiling

How to Use:
The prefabs are all plug-and-play and should work fine in your own scenes without any modifications. The Bath Scene also can be used exactly as it is if you just want to quickly be setup with the scene, although you could also add more details like drains, faucets, and shower which I have also done using other assets from the store independently. There is a bare-bones FPSController script that can be used by doing the same object setup as the Player object in the Bath Scene if you're using the old Unity input system, but this was just used to test things and I would recommend using your own FPSController for most purposes.
